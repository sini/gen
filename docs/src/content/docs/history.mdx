## Where gen comes from

{/* OWNER REVIEW: the lineage paragraph below is the writer's summary, not taken from a primary
source. Check the description of quirks and pipes against den's own docs, or replace it. */}

gen grew out of [den](https://github.com/denful/den), a framework for NixOS, nix-darwin and
home-manager configuration. In den, a *quirk* is a piece of data a scope emits, and a *pipe* moves
quirk data between scopes: from a user up to its host, across the hosts of one environment, or
across every machine in a deployment. gen's graph model and its parametric aspects grew from quirks and pipes: the
scopes became nodes, the movements of data became edges, and a feature that needs its host takes
the host as an argument.
