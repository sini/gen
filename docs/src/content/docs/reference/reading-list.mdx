transcription.

The three source documents — a 47-paper index keyed by which library uses each
paper and whether the influence is major or minor, a keystones document, and a
study guide — are written for people working inside the project. Between them
they carry 129 references to internal architecture decision records and 36 to a
private issue tracker, neither of which resolves for a reader here. Publishing
them verbatim would be publishing dead links.

Until then, [the references](/reference/papers/) carries the bibliography, and
the papers with a summary link to it.
