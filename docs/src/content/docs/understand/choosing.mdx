## Pairs that are easy to mix up

**`includes` or a rule?** Use `includes` when one feature always needs another: `desktop` always
brings `ssh`. Use a rule when a relation depends on facts about the nodes: a webserver reaches a
database only in the same environment and only while the database is up.

**A query or a rule?** A query reads the edges that exist. A rule adds edges. Run the rules
first, then query the combined graph.

**A merge priority or a view order?** A merge priority decides between definitions of one option,
such as the server's own port against a default. A view order decides between contributions that
arrive along different edges, such as a setting from the environment against one from the host.

**An injected argument or an option?** A module reads an injected argument and sets options. The
host a module configures is an argument. The port it opens is an option.

**An attribute or an option?** An option is a value that modules define and gen merges. An
attribute is a value gen computes at a node from an equation, often from the node's position in
the graph, such as a domain inherited from the environment above.

**A name or an identity?** A name is what you call a node. An identity is computed from the
node's kind and its definition. Two nodes of different kinds never share an identity, even when
their names match, and an edit that changes a definition changes its identity.
