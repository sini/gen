## The whole system

Nothing here is hidden behind a facade. Each layer is a set of flakes you can
depend on directly, and the layer above it is the only thing that assumes it.

```mermaid
flowchart TB
  subgraph F["framework"]
    settings & assemble & program & inspect & delivery
  end
  subgraph A["aspects"]
    aspects & link & class
  end
  subgraph M["modules"]
    types & merge
  end
  subgraph S["substrate"]
    prelude & identity & algebra & scope & memo & graph & bind & schema & select & dispatch & product & view
  end
  F --> A --> M --> S
```

Each library belongs to exactly one stratum, and it cannot join the roster
without one. That is not documentation discipline — the declaration is total, so
an unplaced library fails the build.

## Where you plug in

```nix
{ genValues, ... }:
{
  networking.hostName = genValues.hosts.igloo.name;
}
```

One module argument, carrying the resolved configuration as values. gen's types
stay inside the pure evaluation; only values cross.
