## Configuration frameworks ask for a lot of faith

They ask you to believe the abstraction holds at scale, that the escape hatch
stays rare, that the thing evaluates in reasonable time on a fleet rather than a
laptop. Usually you find out otherwise in production.

gen is built the other way round. Every claim on this site is attached to a
mechanism, and the mechanism runs.

## What that buys you

One module argument. The resolved configuration arrives as values, and gen's own
types never leave the pure evaluation.

```nix
{ genValues, ... }:
{
  networking.hostName = genValues.hosts.igloo.name;
}
```

## 22 libraries, each usable alone

Not a framework with an all-or-nothing entry point. Each library is a flake with
one `.lib` export. Depend on the graph algebra and nothing else if that is all
you need — the hub is a convenience, never a requirement.

## The ideas are not new, and we say whose they are

Name resolution as a graph query. Demand-driven incremental recomputation.
Negation in logic programs, and the semantics that make it decidable. These are
settled results, and gen implements them rather than reinventing them.
